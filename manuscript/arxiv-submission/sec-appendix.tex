\section{A checklist for local-inference measurements}\label{app:checklist}
Collected from the failures in \cref{sec:corrections}; each line would have prevented at least one
wrong number in this study.
\begin{enumerate}
\item Record the engine image digest, model file hash and full launch line next to every number.
\item Send an explicit sampling block with every request and assert the server's echo of it.
\item Probe the reasoning state (on/off) with a two-token request before each battery.
\item Launch with automatic context fitting off; assert reported context equals requested context.
\item Accept a context window only after a deep prefill with real text \emph{and} a generation of
known length; read VRAM after the prefill; try a failed rung twice.
\item Re-sweep the layer split after any change of build, cache precision or drafter.
\item For speed: greedy, fixed prompts, a stated filled depth, and an assertion that the generation
reached its requested length. Report accepted length per pass, not acceptance ratio, across drafters.
\item Treat the speculative setting as part of the accuracy configuration.
\item Compare builds on the same items and analyse them as paired; before reporting a null, state the
smallest $p$ the design could return.
\item For output-budgeted tasks with reasoning on, report how many responses finished reasoning.
\item For LLM-judged benchmarks, name the judge and its settings; use two judges and report agreement.
\item Save server logs before removing any container; give every run a unique label that includes every
dimension that varies; make a run that measured nothing fail.
\item Before serving, soak-test a growing multi-turn conversation to the full window and watch host RAM
and swap activity, not only VRAM.
\item Keep per-item records. Recompute headline numbers from them when writing up.
\end{enumerate}
